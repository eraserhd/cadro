# AGENTS.md

This repo is CADro, a ClojureScript/re-frame/CapacitorJS app built with
shadow-cljs.  It implements a new DRO interface and uses Bluetooth SPP to
communicate with TouchDRO-compatible hardware.

The build environment is specified in flake.nix, and you have been started
inside a good dev shell, so you shouldn't need to prefix commands with
`nix develop`.
